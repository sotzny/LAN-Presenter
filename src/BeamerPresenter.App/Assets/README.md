# Anwendungssymbol

`beamer-presenter.png` ist die transparente Vorlage, erstellt mit dem eingebauten
ImageGen-Werkzeug. `beamer-presenter.ico` enthält daraus skalierte 32-Bit-PNG-Bilder
in 16, 20, 24, 32, 40, 48, 64, 128 und 256 Pixeln; der Alphakanal bleibt erhalten.
Das Icon wird in die Programmdatei und als Ressource für Statusfenster und Tray
eingebettet. Inno Setup verwendet dieselbe Datei als Setup-Symbol.

Generierungsprompt:

> Use case: logo-design. Asset type: Windows desktop application icon. Create a single polished stylized video projector (Beamer) symbol for a video presenter app. Square composition, large simple rounded dark projector body, prominent circular luminous lens, two minimal ventilation marks, subtle light beam or play-triangle motif integrated into the lens. Crisp clean geometric silhouette, restrained detail, high contrast and readable at 16x16, tasteful modern desktop icon. The projector occupies most of the canvas with comfortable padding, front three-quarter view. No lettering, no text, no brand, no watermark, no scene or extra objects. Transparent background outside the symbol; deliver a square PNG icon.
